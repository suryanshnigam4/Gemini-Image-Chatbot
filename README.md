# Gemini Chatbot Applications 🤖

This repository contains two AI-powered chatbot applications built using **Python, Streamlit, and Google Gemini API**.

## Applications

### 1. Gemini Text Chatbot
The `QA.py` application allows users to ask questions and receive AI-generated responses using the Gemini API.

### 2. Gemini Image Chatbot
The `img_model.py` application allows users to upload an image and ask questions about it. The Gemini AI model analyzes the image and generates responses.

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- Pillow
- python-dotenv
